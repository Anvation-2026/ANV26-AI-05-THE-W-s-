# Measurements

Generated by `signaltwin-api/scripts/measure.py`. Numbers are from one run on the machine below; they will differ on yours.

Machine: Windows-10-10.0.26300-SP0, 8 cores, 15 GB, Python 3.11.9.

## What these numbers are

Accuracy is measured against a **synthetic** junction with exact ground truth (`signaltwin_api/testing/synth.py`): rectangles on a plan view, coloured by class, with a non-ML blob detector. It tests the counting, queue, wait, speed and saturation logic and the video path (decode, scaling, tracking). It does **not** measure how well YOLO finds vehicles in real footage. No labelled real clip was available, so real-footage accuracy is **not measured**.

## Frame-rate sensitivity (synthetic, exact detections)

The tracker matches boxes between frames, so it needs enough frames per second. From `tests/test_analysis.py` on a 240 s clip with perfect detections: counts are exact at 12.5 frames per second, within 2 percent at 8.3, and within 12 percent at 5. The pipeline processes about 10 frames per second by default and warns below 5.
