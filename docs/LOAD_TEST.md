# Load test

Generated by `signaltwin-api/scripts/load_test.py` against a local API with the synthetic detector. It shows that the API stays responsive while it works. It is not a capacity figure for any server.

Machine: Windows-10-10.0.26300-SP0, 8 cores, Python 3.11.9.

| Test | Result |
| --- | --- |
| 400 health and limits requests, 32 at a time | p50 25 ms, p95 51 ms, p99 74 ms, 0 failures |
| 8 videos (0.3 MB each) uploaded at once | 8 of 8 accepted, slowest 175 ms, all done in 0.2 s |
| 200 health requests while a 120 s video is being analysed | p50 8 ms, p95 16 ms, max 28 ms, 0 failures |
| Cancel of the running analysis | 54 ms until the job reports cancelled |
| 24 demand estimates of 8000 rows, 8 at a time | p50 298 ms, p95 359 ms, 0 failures |
| API memory after the run (API and any worker processes still alive) | 130 MB |
